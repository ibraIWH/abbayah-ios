# Abbayah Store (iOS)

A demo iOS shopping app built with **SwiftUI**, consuming a live backend API.

This project demonstrates real-world mobile development concepts including
API integration, state management, and custom navigation.

---

## Features

- Browse abbayah products
- Filter products by category
- Search products
- View product details
- Custom bottom navigation bar
- Loading, error, and empty states
- Dark mode support

---

## Tech Stack

- SwiftUI
- Async/Await networking
- Custom UI components
- REST API integration

---

## Backend

The app consumes a live Node.js + MongoDB API deployed on Render.

**API Base URL:**  
https://abbayah-backend.onrender.com
